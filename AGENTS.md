# Agent Instructions

Read [.skills/README.md](.skills/README.md) before selecting a workflow skill.

Canonical project decisions live in:

- `CONTEXT.md` — product vocabulary.
- `docs/prd.md` — product requirements.
- `docs/architecture.md` — module boundaries and system seams.
- `docs/conventions.md` — implementation and verification rules.
- `docs/DESIGN.md` — binding UI rules.
- `docs/release.md` and `docs/setup.md` — operational commands and release process.

Work only from an unblocked `.work/` ticket. Do not implement scope that is not stated in an approved ticket. Never place credentials in source control, log device API keys, or make a live dashboard endpoint query PostgreSQL.
